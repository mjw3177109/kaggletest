# 小白说明书｜playground-series-s6e10

> 第一次看 Kaggle、机器学习、CV、排行榜都没关系，这一份只讲人话。

## 01｜这场比赛是干什么的

这场题目要做的事情很简单：**根据乘客的年龄、航程、服务评分、出行类型等信息，预测这个乘客是否满意。**

AI 会先看大量“已经知道满意/不满意答案”的历史数据，然后学习规律，最后去预测 Kaggle 给出的测试数据。

当前自动识别出的目标字段是：`satisfaction`。

## 02｜你现在做到哪一步了

## 03｜5分钟看懂 Kaggle

- `train.csv`：带答案的练习题，AI 用它学习。
- `test.csv`：没有答案的考试题，AI 要预测它。
- `target`：最终要猜的答案，这里是 `satisfaction`。
- `feature`：帮助 AI 判断的线索，比如年龄、飞行距离、服务评分。
- `model`：AI 用来总结规律的算法。
- `CV`：我们自己做的模拟考试成绩。
- `Public LB`：Kaggle 真正给出的线上排行榜成绩。
- `submission.csv`：最终提交给 Kaggle 的答题卡。

## 04｜怎么看分数

这场比赛使用 ROC-AUC，简单理解就是：**越高越好，越接近 1 越强。**


## 07｜常见报错

### RULES_REQUIRED

你还没加入比赛。去 Kaggle 比赛页接受规则，再重跑。

### Missing KAGGLE_API_TOKEN

GitHub 没有拿到 Kaggle Token。检查 Repository Secrets。

### Kernel Failed

Kaggle 云端训练代码出错。看 `kaggle/logs.txt` 或 `kaggle_v21/logs.txt`。

### CV 很高但 LB 很低

说明本地模拟考试和 Kaggle 真考试差异太大，常见原因是过拟合、数据泄漏或验证方式不合理。
