# Kaggle Auto Scientist｜小白说明书标准

每个 `competitions/<比赛名>/` 项目都必须包含一份 `小白说明书.md`。

这份说明书不是给机器学习工程师看的，而是给第一次接触 Kaggle、第一次看到这些文件的人看的。

## 固定要求

1. 先用一句人话解释“这场比赛到底让我干什么”。
2. 用生活类比解释 train / test / target / feature / model / CV / Public LB / submission。
3. 告诉用户项目目录里每个关键文件是干什么的。
4. 用“你只需要做什么”说明如何重跑，不要求用户先懂命令行。
5. 明确哪些事情是自动完成的、哪些仍需要本人操作（例如接受比赛规则）。
6. 展示当前最佳 CV、Public LB、使用模型、是否比上一轮进步。
7. 用表格记录每个 Run：模型、CV、Public LB、结论。
8. 增加“怎么看分数”“为什么本地和 Kaggle 分数不同”“分数高低代表什么”。
9. 增加常见问题：Rules 未接受、Token 失效、Kernel Failed、submission 格式错误、CV 高但 LB 低。
10. 避免只堆术语；出现术语必须同时给一句白话解释。

## 固定章节

- 01｜这场比赛是干什么的
- 02｜你现在做到哪一步了
- 03｜5分钟看懂 Kaggle
- 04｜这份数据有哪些东西
- 05｜AI 是怎么训练的
- 06｜怎么看 CV 和排行榜分数
- 07｜每一轮实验做了什么
- 08｜项目文件夹怎么看
- 09｜如果你想自己运行一次
- 10｜常见报错怎么处理
- 11｜下一步准备怎么提升
- 12｜一句话总结
